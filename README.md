# bus activity

AstrBot 插件：群里问一句「玉林 G02 路有没有车」，直接回当前车辆位置。全国范围可用，不限于玉林。

```
玉林 G02路 现在 1 辆车在路上（掌上公交）
往玉林北站：暂无车
往汽车总站（二医院）：桂K12581D 汽车总站（二医院） 116m
```

## 覆盖

两家上游互补，插件按「掌上公交 → 车来了」顺序试，**有车的那家说了算**：

- 掌上公交：578 个城市/县区名（含县，如陆川、北流、容县），实时车辆带车牌
- 车来了：320 个城市（含香港、台湾、新加坡），其中 20 个是掌上公交没有的（大连、攀枝花等）
- 合并后 598 个城市入口（278 个只有掌上公交有）；两家都查不到就明说查不到，不猜

## 用法

群里直接问，不用指令前缀：

- `玉林 G02 路有没有车`
- `南宁 1 路到哪了`
- `香港 1 路还有几站`
- `陆川 1 路有车吗` —— 县级线路挂在所属地级市目录下，靠线路名前缀认（陆川1路、北流105路）
- `2 路有车吗` —— 不带城市时查配置里的默认城市

线路号前面那串字如果既不是城市也不是已知线路前缀（比如「火星 1 路」），会明说认不出，
不会拿默认城市的线路凑一个答案。

消息里要有「车 / 到哪 / 几站 / 还有 / 来了 / 多久」这类词才回，避免在群里对「前面路堵车了」抢话。

## 配置

`_conf_schema.json` 只有一项：`default_city`（默认 `玉林市`），消息里没写城市时用它。写简称也行，匹配时会去掉「市/区/县/特别行政区」后缀。

## 安装

把整个目录放进 AstrBot 的 `data/plugins/`，WebUI 插件页重载。依赖只有 `cryptography`（AstrBot 自带），无需 `requirements.txt`。

## 自检

```bash
python3 selftest.py          # 离线：解析、匹配、排版（不联网）
python3 selftest.py --live   # 再打三家真接口
```

## 已知边界

- 只答「现在有没有车、车在哪」，不做换乘、到站预测、历史统计
- 「有没有车」＝该线路**两个方向**的在途车辆合计数；某方向空车会照实写「暂无车」
- 车来了部分车队没有车牌，车号显示的是平台内部编号
- 两家站名写法不一致（南宁同一组站，掌上叫「民生新民路口」、车来了叫「新民东葛路口」），所以**一次查询只用一家**，不合并站表
- 非官方接口，上游改协议只需修 `chelaile.py` 或 `query.py` 里对应的一次请求

接口细节见姊妹项目 [yulin-bus-activity](https://github.com/misakano7545/yulin-bus-activity) 的 `docs/掌上公交API.md` 与 `docs/车来了API.md`。
